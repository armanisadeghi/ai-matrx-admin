# Watchtower (admin)

`/administration/agents/watchtower` — every paid button feature checked by a real call. Feature x last canary x result x success x
typical and slow seconds x cost x shape misses x alarm; a row opens its last canary runs (`?feature=<key>`). The data is the
server's watchtower (`aidream/services/watchtower/FEATURE.md`): `tool.feature_scorecard` through `tool.watchtower_snapshot`, runs from
`tool.canary_run`. Champion for the shape: Datadog / Grafana service overview (one row per service, health first, drill to its recent
runs). Built on `MatrxDataTable` (the canonical table) — no page-level styling.

- Alarms reach the super-admin attention dock as source `watchtower` (`features/admin/attention/sources/watchtower.ts`,
  `useWatchtowerSource.ts`, read `tool.watchtower_for_attention`). The daily health note is one `info` item on the dock and the
  sentence above the table.
- Pure words: `words.ts`. Tests: `__tests__/watchtower.test.ts`.
